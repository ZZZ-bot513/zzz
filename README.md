# 基层田径教练员生涯发展报告与展示

本仓库提供一套可生成的中文职业发展材料：一份结构化生涯发展报告（PDF）和一套 **36 页**职业发展展示（PPTX）。核心按“认识职业—能力标准—入门准备—岗位实践—阶段进阶—成果证明—持续发展”展开，强调成长脉络与能力达成路径，不把比赛名次当作唯一发展指标。

## 生成文件

```bash
python -m pip install -r requirements.txt
python generate.py
```

输出到 `output/`：
- `基层田径教练员生涯发展报告.pdf`
- `基层田径教练员生涯发展展示.pptx`

## 中文字体

生成器会自动尝试常见中文字体（Noto Sans CJK、思源黑体、微软雅黑、黑体等）。若当前系统没有可用中文字体，请安装 Noto Sans CJK，例如 Ubuntu/Debian：

```bash
sudo apt-get install fonts-noto-cjk
```

PPTX 使用“微软雅黑”主题字体；若在 Linux 上编辑，请在 PowerPoint/LibreOffice 中选择已安装的中文字体。PDF 会嵌入可找到的中文字体。

## 内容使用说明

材料定位为基层学校、青少年俱乐部、体校/业余训练点等场景的通用发展范本。具体岗位资格、教练员等级申报、竞赛组织、未成年人保护、急救与场地安全要求，应以所在地区体育主管部门、教育部门、协会及用人单位的现行规定为准。报告中的阶段年限是建议性发展节奏，不是法定年限或资格认定承诺。请将示例经历替换为本人真实材料，不虚构资质、带队成绩或训练数据。
